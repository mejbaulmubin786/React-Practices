React-এর মূল ধারণাটি হচ্ছে — "ছোট ছোট অংশে অ্যাপ্লিকেশন তৈরি করে, সেগুলো পুনঃব্যবহারযোগ্য (reusable) করে তোলা" — আর এই অংশগুলোই হচ্ছে **Component**।



## 🧩 ১. কম্পোনেন্ট (Component) কী?

**React Component** হলো একটি **function** (বা class) যা **UI এর একটি নির্দিষ্ট অংশকে উপস্থাপন করে**।

📌 সহজভাবে বলতে গেলে:

> React Component মানে হলো — HTML, CSS এবং JavaScript-কে একত্রিত করে একটি **পুনঃব্যবহারযোগ্য (reusable)** UI ব্লক তৈরি করা।

---

## 🎨 উদাহরণ দিয়ে বোঝা যাক:

ধরা যাক, আমরা একটি বাটনের ডিজাইন বারবার ব্যবহার করতে চাই। আমরা চাই না প্রতি জায়গায় একই কোড লিখি। তাই আমরা নিচের মতো করে একটি কম্পোনেন্ট তৈরি করতে পারি:

```jsx
// MyButton.jsx
function MyButton() {
  return <button className="btn">Click Me</button>;
}
```

এটিই হলো একটি **React Function Component**।

---

## 📦 ২. কম্পোনেন্ট **Export** করা

React Component তৈরি করার পর আপনাকে এটি **export** করতে হয়, যেন আপনি এটি অন্য ফাইলে ব্যবহার করতে পারেন।

### ২টি উপায় আছে:

### ✅ (A) Named Export

```jsx
export function MyButton() {
  return <button>Click</button>;
}
```

**ইমপোর্ট করার সময়:**

```jsx
import { MyButton } from './MyButton';
```

---

### ✅ (B) Default Export

```jsx
function MyButton() {
  return <button>Click</button>;
}

export default MyButton;
```

**ইমপোর্ট করার সময়:**

```jsx
import MyButton from './MyButton';
```

👉 একটি ফাইলে আপনি একটি মাত্র `default export` রাখতে পারেন, কিন্তু অনেকগুলো `named export` রাখতে পারেন।

---

## 🔗 ৩. কম্পোনেন্ট **Import** করে ব্যবহার করা

যখন আপনি অন্য ফাইল থেকে কোনো কম্পোনেন্ট আনবেন, তখন আপনাকে `import` ব্যবহার করতে হবে।

### উদাহরণ:

```jsx
// App.jsx
import MyButton from './MyButton';

function App() {
  return (
    <div>
      <h1>Welcome</h1>
      <MyButton />
    </div>
  );
}

export default App;
```

---

## 🧠 ৪. কম্পোনেন্ট কেমন হয়?

React কম্পোনেন্ট **দুই ধরনের** হয়:

### 🔸 ১. Function Component (সবচেয়ে সাধারণ)

```jsx
function Hello() {
  return <h2>Hello, World!</h2>;
}
```

### 🔸 ২. Class Component (আগে বেশি ব্যবহার হতো, এখন কম)

```jsx
import React, { Component } from 'react';

class Hello extends Component {
  render() {
    return <h2>Hello, World!</h2>;
  }
}
```

বর্তমানে আমরা **Function Component**-ই ব্যবহার করি এবং **Hooks** দিয়ে advanced কাজ করি।

---

## 🔁 ৫. পুনঃব্যবহারযোগ্যতা (Reusability)

React Component বানানোর সবচেয়ে বড় সুবিধা হলো:

* একবার বানালেই আপনি সেটিকে বারবার ব্যবহার করতে পারেন।
* Props দিয়ে customization করতে পারেন।

### উদাহরণ:

```jsx
function Greeting(props) {
  return <h2>Hello, {props.name}!</h2>;
}
```

```jsx
<Greeting name="Mejbaul" />
<Greeting name="Mubin" />
```

> উপরের কম্পোনেন্ট ২ বার ব্যবহৃত হয়েছে, কিন্তু আলাদা আলাদা নামের সাথে।

---

## 📂 ৬. স্ট্যান্ডার্ড ফোল্ডার স্ট্রাকচার

কম্পোনেন্ট গুলো আলাদা ফোল্ডারে রাখতে পারলে কোড পরিষ্কার হয়:

```
src/
├── components/
│   ├── Header.jsx
│   ├── Footer.jsx
│   └── MyButton.jsx
├── App.jsx
├── main.jsx
```

## ✅ সংক্ষেপে পুরো প্রক্রিয়াটি:

| ধাপ | কাজ            | কোড                                                      |
| --- | -------------- | -------------------------------------------------------- |
| 1️⃣ | Component তৈরি | `function MyButton() { return <button>Click</button>; }` |
| 2️⃣ | Export করা     | `export default MyButton;`                               |
| 3️⃣ | Import করা     | `import MyButton from './MyButton';`                     |
| 4️⃣ | ব্যবহার        | `<MyButton />`                                           |

## 🎁 আপনি কী আরও জানতে চান?

* কিভাবে **Props** দিয়ে ডাইনামিক কম্পোনেন্ট তৈরি করা যায়?
* কিভাবে **State** ব্যবহার করে Component এ ইন্টারঅ্যাকশন আনা যায়?
* কিভাবে Component গুলোকে **parent-child** আকারে সংযুক্ত করা যায়?

বললে আমি পরবর্তী ধাপে এগিয়ে যেতে পারি।
