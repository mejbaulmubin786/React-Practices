অবশ্যই! নিচে আমি **React-এর Hooks সম্পর্কে একটি প্রাথমিক এবং সহজবোধ্য আলোচনা** দিলাম, যাতে আপনি একদম নতুন হলেও বিষয়টি ভালোভাবে বুঝতে পারেন।

---

## 🧠 React Hooks: এক নজরে ধারণা

### ✅ Hook কী?

**Hooks** হলো React 16.8 এর পর যুক্ত হওয়া একটি নতুন ফিচার যা দিয়ে আপনি **Functional Component-এর ভিতরে State এবং অন্যান্য React ফিচার ব্যবহার করতে পারেন।**

আগে এগুলো কেবল **Class Component** এর মধ্যেই করা যেত। কিন্তু এখন **Functional Component-এ** সহজভাবে করা যায়।

---

## 🎯 কেন Hooks ব্যবহার করা হয়?

React এ দুটি প্রধান ধরণের কম্পোনেন্ট ছিল:

1. **Class Component** — যেখানে state ও lifecycle method থাকত
2. **Functional Component** — যেখানে শুধু UI দেখানো যেত

👉 কিন্তু Hooks আসার পর, এখন আমরা Functional Component দিয়েই state, lifecycle ইত্যাদি ব্যবহার করতে পারি।

---

## 🔑 জনপ্রিয় কিছু Hooks

| Hook         | কাজ                                                        |
| ------------ | ---------------------------------------------------------- |
| `useState`   | State তৈরি ও পরিবর্তনের জন্য                               |
| `useEffect`  | Side effect পরিচালনার জন্য (যেমন API call, timer, ইত্যাদি) |
| `useContext` | Context API ব্যবহার করতে                                   |
| `useRef`     | DOM element বা value ট্র্যাক রাখতে                         |
| `useReducer` | জটিল state management-এর জন্য                              |
| `useMemo`    | Performance optimization                                   |

## 🧪 উদাহরণ: `useState` এর সহজ ব্যবহার

```jsx
import React, { useState } from 'react';

const Counter = () => {
  const [count, setCount] = useState(0); // initial value 0

  return (
    <div>
      <h2>Count: {count}</h2>
      <button onClick={() => setCount(count + 1)}>Increase</button>
    </div>
  );
};

export default Counter;
```

### 🔍 ব্যাখ্যা:

* `useState(0)` → মানে `count` নামক ভেরিয়েবলের শুরু মান 0।
* `setCount()` → এই ফাংশন দিয়ে আমরা `count` এর মান পরিবর্তন করি।
* এটি React কে বলে দেয়, "state পরিবর্তন হয়েছে, আবার render করো।"

## 🧪 উদাহরণ: `useEffect` এর সহজ ব্যবহার

```jsx
import React, { useState, useEffect } from 'react';

const Timer = () => {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const timer = setInterval(() => {
      setSeconds(prev => prev + 1);
    }, 1000);

    return () => clearInterval(timer); // cleanup
  }, []); // Empty dependency → শুধুমাত্র একবার চালাবে

  return <h2>Timer: {seconds}s</h2>;
};

export default Timer;
```

### 🔍 ব্যাখ্যা:

* `useEffect()` → React Component লোড হবার পর কাজ করে।
* এখানে প্রতি সেকেন্ডে `seconds` বাড়ানো হচ্ছে।
* Return ফাংশন দিয়ে **cleanup** করা হচ্ছে (যেমন component বন্ধ হলে টাইমার বন্ধ করা)।

## 📝 মনে রাখার কিছু গুরুত্বপূর্ণ নিয়ম

1. **Hook কেবল Functional Component বা Custom Hook-এর ভিতরেই ব্যবহার করা যাবে।**
2. **Hook অবশ্যই কম্পোনেন্টের শুরুর দিকে কল করতে হবে**, কোনো শর্তের ভিতর (if/switch) রাখা যাবে না।
3. প্রতিটি Hook React-এর নিজস্ব নিয়ম মেনে চলে, ভুল ব্যবহার করলে সমস্যা দেখাবে।
