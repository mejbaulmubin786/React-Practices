Vite ব্যবহার করে React অ্যাপ্লিকেশন তৈরি করা বর্তমান সময়ের সবচেয়ে দ্রুত এবং সহজ উপায়গুলোর একটি। নিচে আমি সম্পূর্ণ প্রক্রিয়াটি ধারাবাহিকভাবে ব্যাখ্যা করছি যেন আপনি প্রথমবার করলেও কোনো সমস্যা না হয়।

---

## ✅ ধাপ ১: Node.js ইনস্টল আছে কিনা যাচাই করা

Vite ব্যবহারের জন্য আগে আপনার কম্পিউটারে **Node.js** ইনস্টল থাকতে হবে।

### চেক করতে:

```bash
node -v
npm -v
```

না থাকলে [https://nodejs.org/](https://nodejs.org/) থেকে LTS ভার্সনটি ডাউনলোড ও ইনস্টল করুন।

---

## ✅ ধাপ ২: Vite + React প্রোজেক্ট তৈরি করা

Vite CLI দিয়ে React প্রোজেক্ট তৈরি করতে নিচের কমান্ড ব্যবহার করুন:

```bash
npm create vite@latest
```

**তারপর:** CLI আপনাকে কিছু প্রশ্ন করবে:

```

✔ Select a framework: » React
✔ Select a variant: » JavaScript or TypeScript
```

> 👉 আপনি চাইলে `my-react-app` এর জায়গায় অন্য নামও দিতে পারেন।


## 🔍 **প্রতিটি ফাইল ও ফোল্ডারের ব্যাখ্যা**

### 📁 `node_modules/`

* এখানে সব **dependency package** থাকে যেগুলো `npm install` এর মাধ্যমে ইনস্টল হয়।
* সাধারণত এটি গিটে রাখা হয় না (`.gitignore` এ থাকে)।
* এটি আপনার কোড নয়, বরং অন্যদের কোড (যেমন React, Vite ইত্যাদি লাইব্রেরি)।

---

### 📁 `public/`

* এই ফোল্ডারে আপনি এমন ফাইল রাখতে পারেন যেগুলো **publicly accessible** হবে (e.g. ইমেজ, ফন্ট, favicon ইত্যাদি)।
* এখানে থাকা ফাইলগুলো সরাসরি URL দিয়ে এক্সেস করা যায়, যেমন: `/vite.svg`
* এটি Webpack-এর `public/` ফোল্ডারের মতোই।

---

### 📁 `src/`

* এটি আপনার **মূল অ্যাপ্লিকেশনের সোর্স কোড** রাখার জায়গা।

#### 📄 `App.jsx`

* এটি হলো মূল **React কম্পোনেন্ট** (Parent Component)।
* আপনি এখান থেকে অন্য সব component কল করেন।

#### 📄 `main.jsx`

* এটি হলো React অ্যাপের **entry point**। এখানে ReactDOM দিয়ে `<App />` কে DOM-এ রেন্ডার করা হয়।

```jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App.jsx'
import './index.css'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
```

#### 📄 `App.css`, `index.css`

* এখানে আপনার **CSS স্টাইলিং** রাখা হয়।
* `App.css`: App কম্পোনেন্টের জন্য স্টাইল
* `index.css`: গ্লোবাল স্টাইল যেমন body, html, reset ইত্যাদি

---

### 📄 `index.html`

* এটি হলো মূল **HTML টেমপ্লেট** ফাইল।
* এখানে `<div id="root"></div>` থাকে যেখানে React অ্যাপটি রেন্ডার হয়।
* এখানে আপনি মেটা ট্যাগ, favicon, টাইটেল ইত্যাদি যুক্ত করতে পারেন।

```html
<body>
  <div id="root"></div>
  <script type="module" src="/src/main.jsx"></script>
</body>
```

---

### 📄 `package.json`

* আপনার প্রজেক্টের **dependency, script, নাম, ভার্সন** ইত্যাদি এখানে থাকে।
* যেমন:

```json
{
  "name": "my-react-app",
  "version": "0.0.0",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^18.0.0",
    "react-dom": "^18.0.0"
  },
  "devDependencies": {
    "vite": "^5.0.0"
  }
}
```

---

### 📄 `vite.config.js`

* এই ফাইলটি Vite-এর **কনফিগারেশন ফাইল**।
* আপনি এখানে প্লাগইন, path alias, SSR, proxy ইত্যাদি কনফিগার করতে পারেন।

```js
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
})
```

---

### 📄 `.gitignore`

* এখানে উল্লেখ করা ফাইল বা ফোল্ডারগুলো **Git এ track করা হবে না**।
* যেমন: `node_modules/`, `.env` ইত্যাদি

---

### 📄 `README.md`

* এই ফাইলে আপনি প্রজেক্টের **ব্যবহারবিধি, ইনস্টলেশন গাইড**, এবং অন্যান্য তথ্য লিখতে পারেন।

## 📄 `package.json` ফাইলের ডাটা বিশ্লেষণ

আপনার দেওয়া JSON অনুযায়ী নিচে প্রতিটি অংশ বিশ্লেষণ করছি:

```json
{
  "name": "project1",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview"
  },
  "dependencies": {
    "react": "^19.1.0",
    "react-dom": "^19.1.0"
  },
  "devDependencies": {
    "@eslint/js": "^9.25.0",
    "@types/react": "^19.1.2",
    "@types/react-dom": "^19.1.2",
    "@vitejs/plugin-react": "^4.4.1",
    "eslint": "^9.25.0",
    "eslint-plugin-react-hooks": "^5.2.0",
    "eslint-plugin-react-refresh": "^0.4.19",
    "globals": "^16.0.0",
    "vite": "^6.3.5"
  }
}
```

---

## 🔍 ১. `"name": "project1"`

* এটি হলো প্রজেক্টের নাম।
* এটি `npm` বা `yarn` প্যাকেজ হিসেবে প্রকাশ করার সময় ব্যবহৃত হয়।
* **নাম সবসময় ইউনিক** হওয়া উচিত যদি আপনি পাবলিক npm-এ প্রকাশ করতে চান।

---

## 🔍 ২. `"private": true`

* যদি এটি **`true`** থাকে, তাহলে এই প্রজেক্টটি **npm registry-তে প্রকাশ** (publish) করা যাবে না।
* এটি সাধারণত ব্যক্তিগত/ইনহাউস প্রজেক্টের জন্য রাখা হয়।

> ⚠️ ভালো প্র্যাকটিস: গোপন প্রজেক্টের জন্য সবসময় `"private": true` রাখুন।

---

## 🔍 ৩. `"version": "0.0.0"`

* এটি প্রজেক্টের বর্তমান ভার্সন।
* আপনি যখন কোনো `npm publish` বা release তৈরি করবেন, তখন এই ভার্সন বাড়ানো হয় (`0.1.0`, `1.0.0` ইত্যাদি)।

---

## 🔍 ৪. `"type": "module"`

* এটি নির্দেশ করে যে আপনি **ES Modules (ESM)** ব্যবহার করছেন, অর্থাৎ `import`/`export` সিনট্যাক্স ব্যবহার করবেন।
* যদি এটি না থাকে, তাহলে Node.js `require()`/`module.exports` ধরবে।

---

## 🔍 ৫. `"scripts"` অংশ

এই অংশে আপনি **কাস্টম কমান্ড** সেট করতে পারেন যেগুলো `npm run` দিয়ে চালানো যায়।

```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "lint": "eslint .",
  "preview": "vite preview"
}
```

### 🔹 `"dev": "vite"`

* এটি Vite-এর **development server** চালায়।
* আপনি টার্মিনালে লিখলে:

  ```
  npm run dev
  ```

  এটি বাস্তবে চালায়:

  ```
  vite
  ```

🔁 এখন আপনি যদি `"dev"` এর বদলে অন্যকিছু লেখেন, যেমন:

```json
"scripts": {
  "start": "vite"
}
```

তাহলে আপনাকে কমান্ড দিতে হবে:

```bash
npm run start
```

👉 অর্থাৎ `npm run` এর পর `"scripts"` এর key ব্যবহার করা হয়।

**উদাহরণ:**

```json
"scripts": {
  "hello": "echo Hello, World!"
}
```

এখন চালালে:

```bash
npm run hello
```

আউটপুট হবে:

```
Hello, World!
```

---

### 🔹 `"build": "vite build"`

* প্রোডাকশন রেডি বান্ডেল তৈরি করে। কমান্ড:

  ```
  npm run build
  ```

### 🔹 `"preview": "vite preview"`

* `build` করার পর লোকাল সার্ভারে প্রিভিউ দেখতে পারবেন।

  ```
  npm run preview
  ```

### 🔹 `"lint": "eslint ."`

* এটি আপনার কোডে লিন্টিং করে (code quality check)।

---

## 🔍 ৬. `"dependencies"` vs `"devDependencies"`

| ধরন               | উদাহরণ           | ব্যবহার                             |
| ----------------- | ---------------- | ----------------------------------- |
| `dependencies`    | react, react-dom | প্রোডাকশনে প্রয়োজন                  |
| `devDependencies` | vite, eslint     | শুধুমাত্র ডেভেলপমেন্ট টাইমে প্রয়োজন |

---

### 🔹 `"react"` ও `"react-dom"`:

* React অ্যাপের প্রধান লাইব্রেরি।
* `react` হলো কম্পোনেন্ট লাইব্রেরি, `react-dom` তা DOM-এ রেন্ডার করে।

### 🔹 Vite ও Plugins:

* `"vite"`: দ্রুত dev server এবং build tool
* `"@vitejs/plugin-react"`: React-এর জন্য Vite প্লাগইন
