## 📘 React Components, Props ও Dynamic UI: একটি পূর্ণাঙ্গ ধাপে ধাপে গাইড

### 🔹 ধাপ ১: কমপোনেন্ট কী?

React-এ **কমপোনেন্ট** হলো একটি ফাংশন যা UI এর নির্দিষ্ট অংশ রেন্ডার করে। এটি HTML কোডের মতো দেখতে হলেও এটি JSX এর মাধ্যমে লেখা হয়। কমপোনেন্ট গুলো আমরা তৈরি করি যাতে করে **কোড রিপিট না করে বারবার ব্যবহার** করা যায়।

📌 **দুই প্রকার কমপোনেন্ট**:

1. **Stateless Functional Component**
2. **Class-based Component** (এখন কম ব্যবহৃত হয়)

আমরা এখানে ব্যবহার করবো **Stateless Functional Component**, যা একটি ফাংশনের মতো দেখতে।

### 🔹 ধাপ ২: একটি সিম্পল কমপোনেন্ট তৈরি (Title.jsx)


```jsx
import React from 'react';
```

```jsx
import React from 'react';
```

* `App.jsx` ফাইলে আমরা এটি **ইমপোর্ট করে ব্যবহার** করেছি।

### 🔹 ধাপ ৪: Props দিয়ে Dynamic Card

#### ✅ App.jsx

```jsx
<Card 
  title="Card 1" 
  text="This is Card 1" 
  btn="Visit Now" 
/>
<Card 
  title="Card 2" 
  text="This is Card 2" 
  btn="Learn More" 
/>
```

#### ✅ Card.jsx

```jsx
import React from 'react';

const Card = (props) => {
  return (
    <div className="card" style={{ width: '18rem' }}>
      <img src="..." className="card-img-top" alt="..." />
      <div className="card-body">
        <h5 className="card-title">{props.title}</h5>
        <p className="card-text">{props.text}</p>
        <a href="#" className="btn btn-primary">{props.btn}</a>
      </div>
    </div>
  );
};

export default Card;
```

#### ✅ আরও সহজ করতে Destructuring:

```jsx
const Card = ({ title, text, btn }) => {
  return (
    <div className="card" style={{ width: '18rem' }}>
      <img src="..." className="card-img-top" alt="..." />
      <div className="card-body">
        <h5 className="card-title">{title}</h5>
        <p className="card-text">{text}</p>
        <a href="#" className="btn btn-primary">{btn}</a>
      </div>
    </div>
  );
};
```

| বিষয়            | কাজ                                           |
| --------------- | --------------------------------------------- |
| `Component`     | কোডের ছোট টুকরো, আলাদা ফাইল                   |

| `Dynamic Class` | Design বা style প্রপস দিয়ে ক্লাস নাম পাল্টানো |
| `Reusable`      | একবার কমপোনেন্ট লিখে বারবার ব্যবহার করা যায়   |

## 🧠 JSX এর কিছু বিশেষ নিয়ম

1. একাধিক HTML ট্যাগ return করতে চাইলে `<></>` বা `<div>` দিয়ে wrap করতে হবে।
2. `class` নয়, `className` লিখতে হয়।
3. `style={{}}` এর মাধ্যমে inline style দিতে হয়।
4. JSX-এ JavaScript expression লিখতে চাইলে `{}` ব্যাবহার করতে হয়।

খুব ভালো! আপনি এখন **React-এ "type" নামের একটি Prop দিয়ে কীভাবে কোনো উপাদান (যেমন: বাটন) শর্তসাপেক্ষে দেখানো বা না দেখানো যায়**, সেটা নিয়ে জানতে চাচ্ছেন। আমরা এখন ধাপে ধাপে এই বিষয়টি বিস্তারিতভাবে ব্যাখ্যা করবো — **Context পরিবর্তন, Style পরিবর্তন ও Type (শর্ত)** মিলিয়ে একটি পূর্ণ উদাহরণ দিয়ে।

## 🔶 লক্ষ্য

আমরা এমন একটি **Card কমপোনেন্ট** তৈরি করবো যেখানে:

* `title`, `text`, এবং `design` প্রপস থাকবে।
* চাইলে **button দেখানো হবে**, আবার চাইলে **না দেখানো** হবে।
* এবং চাইলে **button-এর type অনুযায়ী ভিন্ন style বা content** হবে।

## ✅ Step-by-Step ব্যাখ্যা

### 📁 Card.jsx

```jsx
import React from 'react';

const Card = ({ title, text, btn, design, showButton, type }) => {
  return (
    <div className={`card ${design}`} style={{ width: '18rem' }}>
      <img src="https://via.placeholder.com/150" className="card-img-top" alt="..." />
      <div className="card-body">
        <h5 className="card-title">{title}</h5>
        <p className="card-text">{text}</p>

        {/* ✅ Button conditionally show */}
        {
          showButton
            ? (
              type === "primary"
                ? <a href="#" className="btn btn-primary">{btn}</a>
                : <a href="#" className="btn btn-secondary">{btn}</a>
            )
            : null
        }

      </div>
    </div>
  );
};

export default Card;
```

---

### 🧾 ব্যাখ্যা

| প্রপস        | উদ্দেশ্য                               |
| ------------ | -------------------------------------- |
| `title`      | কার্ডের শিরোনাম                        |
| `text`       | কার্ডের বর্ণনা                         |
| `btn`        | বাটনে দেখানোর টেক্সট                   |
| `design`     | ব্যাকগ্রাউন্ডের CSS class              |
| `showButton` | বাটন দেখাবো কিনা (boolean)             |
| `type`       | বাটনের টাইপ – `primary` বা `secondary` |

---

### 📁 App.jsx (ব্যবহার)

```jsx
import React from 'react';
import Card from './components/Card';

const App = () => {
  return (
    <div>
      {/* ✅ একটি কার্ডে বাটন আছে */}
      <Card
        title="Card 1"
        text="This is card 1"
        btn="Click Me"
        design="design-one"
        showButton={true}
        type="primary"
      />

      {/* ✅ একটি কার্ডে বাটন আছে, কিন্তু type secondary */}
      <Card
        title="Card 2"
        text="This is card 2"
        btn="Learn More"
        design="design-two"
        showButton={true}
        type="secondary"
      />

      {/* ❌ একটি কার্ডে বাটনই নেই */}
      <Card
        title="Card 3"
        text="This is card 3 without a button"
        design="design-three"
        showButton={false}
      />
    </div>
  );
};

export default App;
```

## 🧠 মনে রাখুন

| ধারণা                                 | উদাহরণ                                    |
| ------------------------------------- | ----------------------------------------- |
| শর্তসাপেক্ষে JSX দেখানো               | `{ showButton ? <a>...</a> : null }`      |
| প্রপস থেকে টাইপ ধরে UI পরিবর্তন       | `type === 'primary' ? ... : ...`          |
| স্টাইল কাস্টমাইজ                      | `className={design}`                      |
| ব্যবহারকারী ইচ্ছামত ডাটা পাঠাতে পারবে | `<Card title="..." showButton={false} />` |

## ✅ উপসংহার

এইভাবে `props` ও শর্তযুক্ত rendering ব্যবহার করে আপনি:

* একটি কমপোনেন্টকে **reuseable**, **dynamic**, ও **শর্ত-ভিত্তিক** করতে পারবেন।
* একই কমপোনেন্ট ব্যবহার করে অনেক রকম UI তৈরি করতে পারবেন।
* ভবিষ্যতে আরও অনেক কাস্টম আচরণ সহজেই যুক্ত করতে পারবেন।
